# أكوادي — احفظ أكواد Swift وHTML 🃏

تطبيق ويب تعليمي بواجهة عربية لحفظ أكواد **Swift** و**HTML** باستخدام بطاقات مراجعة (Flashcards) ونظام **التكرار المتباعد**.

## المزايا

- **بطاقات إكمال الكود**: تعرض البطاقة كودًا فيه فراغات، وتكتب الجزء الناقص مباشرة داخل الكود.
- **تحقق تلقائي** من الإجابة (يتجاهل المسافات، ولا يميّز حالة الأحرف في HTML)، مع إظهار الإجابة الصحيحة عند الخطأ.
- **تلميح** يكشف حرفًا واحدًا في كل مرة.
- **تكرار متباعد** مبني على خوارزمية SM-2: مرة أخرى / صعب / جيد / سهل، مع عرض موعد المراجعة القادم لكل خيار.
- **45 بطاقة جاهزة**: أساسيات Swift و SwiftUI، وأساسيات HTML والوسوم الدلالية والنماذج.
- **أضف بطاقاتك الخاصة** مع معاينة فورية، وتعديلها أو حذفها.
- **إحصاءات**: أيام متتالية، دقة اليوم، التقدّم في كل لغة، ونشاط آخر 14 يومًا.
- **مراجعة حرّة** للتدرّب دون التأثير على الجدولة.
- تصدير واستيراد نسخة احتياطية (JSON)، ويُحفظ التقدّم تلقائيًا في المتصفح.
- وضع داكن تلقائي، وتصميم متجاوب للجوال، واختصارات لوحة المفاتيح.

## التشغيل

لا يحتاج أي تثبيت أو بناء — افتح `index.html` في المتصفح مباشرة، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| `Enter` | الانتقال للفراغ التالي / التحقق |
| `Ctrl + Enter` | التحقق مباشرة |
| `1` `2` `3` `4` | مرة أخرى / صعب / جيد / سهل |

## كتابة بطاقة جديدة

ضع الجزء المخفي بين `{{` و `}}`، ويمكن تحديد أكثر من إجابة صحيحة بالفاصل `|`:

```swift
for i in 1{{...|..<}}5 {
    {{print}}(i)
}
```
